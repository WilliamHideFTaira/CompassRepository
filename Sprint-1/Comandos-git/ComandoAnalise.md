# Comandos de análise e inspeção

O Git dispõe de uma série de comandos para auxiliar na análise do repositório. São eles:

* `git show` - mostra o branch atual e seus commits. Adicionando a tag no final do comando, é possível exibir a informação delas também;
* `git diff` - exibe as diferenças do branch atual com o branch remoto;
* `git shortlog` - mostra um log resumido do projeto, cada commit sendo unido por **nome do autor**;
* `git describe --tags` - verifica todas as tags do projeto;
