# Comandos de editores de texto

O Linux dispõe de alguns editores de texto no terminal. Abordaremos dois aqui:

1. **Nano** é um editor de texto simples, projetado para ser amigável e intuitivo, ótimo para usuários iniciantes:
    * `nano` - cria arquivo;
    * _Ctrl + o_ - salva arquivo;
    * __Ctrl + x_ - fecha arquivo;
    * `nano file` - abre arquivo;
    * _Ctrl + r_ - pega conteúdo do arquivo;
    * _Alt + a_ - modo de seleção de texto;
    * _Alt + 6_ - copia texto;
    * _Ctrl + u_ - cola texto;
    * _Ctrl + k_ - recorta texto;
    * _Alt + /_ - fim do arquivo;
    * Alt + \ - início do arquivo;
    * _Alt + g_ - linha específica;
    * _Ctrl + w_ - busca por palavra;
    * _Alt + r_ - busca e replace;

2. **Vim** já uma versão avançada do editor "Vi", projetado para ser poderoso, flexível e eficiente. Possui dois modos principais: **modo de comando** e **modo de inserção**:

    * _i_ - modo de inserção;
    * _esc_ - modo de comandos;
    * `vim file` - cria e abre arquivo;
    * _x_ - salva arquivo;
    * _q_ - sai do editor;
    * _:q!_ - sai do editor sem salvar;
    * _:x!_ - salva e sai do editor;
    * _dd_ - deleta linha;
    * _u_ - undo (desfaz);
    * _Ctrl + r_ - redu (refaz);
    * _/word_ - busca palavra;
    * _Enter_ - primeira ocorrência de palavra;
    * _n_ - próxima ocorrência;
    * _shift + n_ - ocorrência anterior;
    * `%/word/word2` - replace (substitui palavra);
